# Flurry

> Flurry is a mobile app analytics platform originally built by Flurry, Inc. and acquired by Yahoo. It provided event/session analytics, audience segmentation, funnels, crash and performance metrics, push messaging, and remote config for iOS, Android, Flutter, React Native, and Unity apps via client-side SDKs. The Flurry Analytics service sunset on 2024-03-15; the SDKs and developer resources remain published. Backed historically by Union Square Ventures and Version One Ventures.
